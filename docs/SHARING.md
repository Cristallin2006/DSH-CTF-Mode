## English

**Turn your DeepSeek into a full-stack CTF team.**

DSH-CTF-Skill brings specialist CTF methods to DeepSeek Harness, with optional continuable Solvers, scoped structured memory and evidence review. Start with skills; add experimental orchestration when a task benefits from independent work or review.

The preview includes a read-only installer plan, prerequisite checks and two reproducible synthetic examples: Python-only byte recovery and native Solver/memory boundaries with a deterministic local adapter. No external model calls are needed for either example.

Historical result: TSecBench v1 **local mode**, 2026-10-18 — 96.94 composite, 71/74 flags. This is one local run, not a new evaluation of this preview release or a general performance guarantee.

Try it: https://github.com/Cristallin2006/DSH-CTF-Skill

Installation feedback, compatibility fixes and small reproductions are welcome. Star it if it helps your workflow.
