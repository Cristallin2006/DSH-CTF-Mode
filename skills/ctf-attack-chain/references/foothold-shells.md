# 立足点：确认身份、通道与运行条件

已有账号时可使用目标提供的 SSH/管理入口；已有单次执行能力时，按任务需要判断是否需要交互通道。保留 host key 核验，不把关闭核验写成默认命令。

```bash
ssh user@TARGET
ssh -i TARGET_KEY user@TARGET
id
hostname
uname -a
sudo -l
ss -tlnp
```

按当前问题选择这些观察，不要求每次完整画像。记录实际用户、组、工作目录、容器/主机边界、会话过期和重置条件。网络回连、端口转发、上传工具或修改访问配置是额外干预，执行前确认当前授权与实际需要，不自动写入 authorized_keys 或建立持久通道。

需要终端的交互场景可尝试目标已有 PTY 工具；缺少 PTY 不代表所有 sudo/ssh 调用都不可用，取决于工具参数、输入方式和目标策略。

```bash
python3 -c 'import pty; pty.spawn("/bin/bash")'
```

面板中的备份、应用配置、用户与日志可作为下一段证据来源。访问成功、某条命令成功和稳定会话分别报告；确认一次输出来自当前目标，不把缓存输出当作执行结果。收集到的候选按 flag-collection.md 保留出处与实例。
