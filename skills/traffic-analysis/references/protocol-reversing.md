# 未知协议与 pcap + 二进制互证

用于非标准协议、字段结构未知或同时给出客户端/服务端二进制的场景。先保留原始捕获、格式、链路类型、截断与包序，再分会话和方向；标准协议可作为载体，不因像 HTTP/TLS 就判为诱饵，高熵也可能是密文或压缩数据。

## 1. 字段与边界候选

逐偏移统计恒值、单调性、离散值域、可打印率、熵和覆盖样本数；它们分别可提示头部/版本、计数、类型、文本或未知数据，但均不唯一。长度相关性要同时尝试端序、单位、头尾开销和分片；TCP 包边界不等于应用消息边界。

`scripts/field_infer.py` 按有向五元组统计 TCP/UDP 的捕获 payload，不混合相同端口的不同主机。它不去除 TCP 重传、不识别应用分帧，因此重复数据会改变统计。稀疏位置不与充分采样位置混为同等证据。

候选信道的信息量估计需注明独立性、字段取值域和已知长度假设；经验熵×包数只是估计，不能作为普遍不可恢复证明。

## 2. 重复键冲突与组合编码

同逻辑键字段冲突可能来自键碰撞、不同连接、抓包/解析错误、重传重叠、状态变化或组合字段。先核对键与会话，再按线索生成单字段/多字段 XOR、加减、置换或后变换假设，不强制升级到某一组合层数。

`conflict_oracle.py` 的一致性排名用于生成假设。消除冲突可能是退化解或过拟合，需在独立样本/已知约束验证；保留冲突也不自动排除真实编码。

`scripts/stream_reassemble.py` 保留捕获顺序下首次观察到的字节，报告重叠冲突与缺口。这个选择只是一种重组策略，不证明目标 TCP 栈采纳同一字节。缺口输出用零填充并明确标记；带缺口产物不能当作完整原始流。只支持经典 pcap、IPv4 TCP 和单连接实例，其他范围看工具 --describe。

## 3. 编码、压缩与加密候选

已知明文可检查 XOR 差分、重复周期、块边界和握手字段；等长高熵不独指 RC4，相同/不同密文块也不足以在一般条件下区分 ECB/CBC。IV、nonce、salt、KDF 及算法身份需由结构、源码或可重复实验支持。base64/hex 字符集是编码线索，仍需核对字母表和 padding。

## 4. 与二进制互证

多层 relay 的前缀归属、注入式分帧适配器和同连接状态见 pwn-exploit/references/relay-session-contracts.md。捕获重组、应用分帧与请求是否已消费分别说明，不把包序号/重传当应用 epoch 或安全重放证明。

流量侧交接包/流位置、方向、字段偏移/端序、重组策略、缺口/冲突与候选公式。逆向侧交接解析断言、状态机、长度字段、常量/表的地址与消费方式。

未引用的固定表可能是置换/替换/密钥材料，也可能是无关或未识别引用数据；验证尺寸、访问者和正逆关系后再带回流量解码。可运行二进制时使用已知输入和初始化状态对拍，说明本地后端与捕获实例差异。

## 5. 多层材料与负结果

短记录（例如 TXT/服务发现）中的值可以生成密钥假设，大块流可按实际协议/魔数检查容器或压缩数据；“TLS 端口”不证明 payload 已加密。两份等长数据经变换后按可打印性拼接仅是候选，多个可打印值/均不可打印的位置须保留歧义，并用结构、校验或目标验证约束。

每层保留输入/输出 hash、顺序、参数、原始长度与覆盖范围。负结果限定已测字段、键、公式、路径和环境；未发现不等于不可恢复，也不要求穷举全部未知空间才允许交付未完成报告。

当校验字段已明确为 CRC 时，按需转 `ctf-crypto/references/crc-oracle-contracts.md` 核对覆盖字节、反射、仿射基线和样本契约；不要把长度/高熵相关性直接升级为 CRC 或密钥恢复结论。
