# 登录受阻：优先检验信息缺口

回查完整题目、附件、页面/JS/注释、公开配置与错误响应，区分“缺少必要输入”“认证假设错误”和“目标退化”。原文用可核对来源获取，不能只信子代理摘要。容器内配置只在已有入口与相应授权时检查，不把读不到的内部文件列为必须完成的前置步骤。

尝试候选前分别判断：是否获准、来源是否支持、成本是否值得、运行预算是否足够。派生词表写明来源、规则、去重数量和预期区分的假设；派生不等于自动合法或有效，通用字典也不一概非法。同网段不代表允许跨题复用凭据。

记录最小请求基线，比较状态、内容、时间与会话条件。连接复用不代替限速，线程数不等于实际请求速率。异常、重复同质响应或无信息收益时重审前提。受控任务只能使用 dsh_control；现有 async_fuzz.py 和任意网络脚本不属于受控执行器的自动覆盖范围。

hint 的收益按可能提供的信息、成本、剩余时间和替代实验评估；信息缺口也可能适合买 hint。主代理复核原材料和阻塞条件，不只依赖子代理自报。
